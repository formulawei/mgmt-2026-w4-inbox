# MGMT 2026 Week 4 — Problem Diagnosis Lab

A bilingual, self-contained activity for SCQA, causal reasoning, issue trees, and AI-assisted auditing.

## Use

- Open `index.html` directly for offline use.
- For GitHub Pages, upload `index.html` and `.nojekyll` to the repository root.
- No build, server, account, API, or API key is required.

## Learning sequence

1. Individual SCQA and an initial solution temptation.
2. Group classification of evidence, symptoms, hypotheses, and unknowns.
3. Initial question and causal pyramid.
4. AI Task 1: audit the real question.
5. Human revision of the question.
6. AI Task 2: audit causal logic and the pyramid.
7. Human selection of the problem sweet spot and final judgment.

## Privacy

Answers remain in the current browser through `localStorage`. Do not enter names, student IDs, personal data, or confidential business information. Export a Markdown or HTML learning note before leaving class; use JSON to move work between devices.
